# TELEPROMPTER — SHORT 21–30 (BAHASA SEHARI-HARI)

Naskah ini sudah diubah ke bahasa yang lebih natural dan enak diucapkan di depan kamera. Kalimat dibuat lebih pendek, lebih seperti orang sedang ngobrol, dan tetap mempertahankan inti gagasan setiap short.

## SHORT 21 — Kenapa Rumah Kita Bisa Jadi Gudang Barang yang Jarang Dipakai?

Pernah nggak / pas lagi beres-beres rumah / kamu nemu kardus atau barang lama / yang udah bertahun-tahun nggak pernah dipakai? //

Tapi begitu mau dibuang...

/ tangan malah berhenti. //

“Jangan dibuang dulu deh... / siapa tahu nanti kepakai.” //

Padahal kalau dipikir-pikir...

/ barang itu cuma numpuk di pojokan. /

Berdebu. /

Dan kita sendiri / bahkan lupa terakhir kali memakainya kapan. //

Masalahnya...

/ rumah kita itu sebenarnya punya ruang yang terbatas. //

Apalagi kalau tinggal di kota besar. //

Setiap meter persegi rumah / kita bayar mahal. //

Bisa lewat harga rumah... /

bisa juga lewat uang sewa. //

Jadi ketika kita menumpuk barang yang udah nggak pernah dipakai...

/ sebenarnya kita sedang memakai ruang rumah yang mahal / cuma buat menyimpan barang yang nggak memberi manfaat lagi. //

Dan lucunya...

/ kita sering merasa sayang membuang barang sendiri. //

Karena di kepala kita ada pikiran:

“Siapa tahu nanti butuh.” //

Padahal...

/ bisa jadi yang sebenarnya kita korbankan / bukan barangnya. //

Tapi **RUANG HIDUP KITA↘**. //

Coba deh / lihat sudut rumah kamu hari ini. //

Ada nggak barang yang sudah bertahun-tahun nggak pernah kamu sentuh? //

Jangan-jangan...

// KITA BUKAN KEKURANGAN TEMPAT / TAPI TERLALU BANYAK MENYIMPAN BARANG YANG SUDAH NGGAK KITA BUTUHKAN↘. //

## SHORT 22 — Kenapa Rumah Modern Semakin Berisik Walau Pintu Sudah Ditutup?

Pernah heran nggak...

/ kenapa di rumah cluster atau apartemen sekarang / suara tetangga bisa kedengeran jelas banget? //

Suara pintu. /

Langkah kaki dari lantai atas. /

Bahkan kadang / orang ngobrol pun masih samar-samar kedengeran. //

Padahal...

/ pintu dan jendela udah ditutup. //

Kita sering mikir:

“Wah... / tetangganya berisik banget.” //

Tapi ternyata...

/ masalahnya nggak selalu di tetangga. //

Bisa jadi / memang dari bangunannya. //

Rumah zaman dulu / banyak yang pakai dinding bata yang cukup tebal. //

Jarak antar rumah juga / kadang masih punya halaman yang cukup luas. //

Nah, sekarang...

/ karena rumah harus dibangun lebih cepat / dan biaya pembangunan harus ditekan... //

banyak hunian modern / menggunakan material yang lebih ringan. //

Masalahnya...

/ semakin ringan dan tipis sebuah dinding / suara juga bisa lebih gampang menembus. //

Apalagi kalau suara datang dari lantai atas. //

Getaran langkah kaki / bisa ikut merambat lewat struktur bangunan. //

Jadi...

/ rumah modern memang bisa kelihatan rapi / minimalis / dan keren. //

Tapi belum tentu...

/ **TENANG↘**. //

Karena pada akhirnya...

// YANG KITA BUTUHKAN DI RUMAH / BUKAN CUMA PRIVASI DARI PANDANGAN / TAPI JUGA PRIVASI DARI SUARA↘. //

## SHORT 23 — Kenapa Rumah Modern Membuat Kita Lupa Kapan Malam Dimulai?

Pernah kepikiran nggak...

/ kenapa sekarang banyak orang / susah banget tidur sebelum larut malam? //

Kita biasanya langsung menyalahkan HP. //

“Ah... / kebanyakan main HP.” //

Dan memang / layar HP bisa jadi salah satu penyebab. //

Tapi ada hal lain yang sering kita lupa. //

**RUMAH KITA SENDIRI↘.** //

Dulu...

/ rumah sangat bergantung pada cahaya matahari. //

Pagi terang. /

Sore mulai redup. /

Malam... / ya gelap. //

Tubuh kita / terbiasa mengikuti perubahan itu. //

Tapi sekarang...

/ malam pun rumah kita bisa tetap terang seperti siang. //

Lampu LED menyala. /

TV menyala. /

Layar laptop menyala. /

HP juga menyala. //

Akibatnya...

/ suasana rumah nggak pernah benar-benar memberi sinyal:

“Udah malam.” //

Padahal tubuh kita / punya ritme sendiri untuk bersiap tidur. //

Jadi kadang...

/ bukan cuma kita yang susah berhenti kerja atau main HP. //

**RUMAH KITA JUGA NGGAK PERNAH BENAR-BENAR GELAP↘.** //

Coba malam ini...

/ satu jam sebelum tidur / mulai redupkan lampu kamar. //

Matikan lampu yang nggak perlu. //

Bikin suasananya lebih tenang. //

Karena mungkin...

// RUMAH BUKAN CUMA TEMPAT KITA TIDUR / TAPI JUGA TEMPAT YANG MEMBANTU TUBUH KITA TAHU / KAPAN SAATNYA BERHENTI↘. //

## SHORT 24 — Kenapa Kita Sering Bangun Tidur Merasa Lelah di Kamar Ber-AC?

Pernah nggak...

/ kamu tidur delapan jam di kamar ber-AC... //

suhunya enak... /

nggak begadang...

tapi pas bangun...

/ badan malah terasa berat? //

Kepala agak pusing. /

Leher kaku. /

Dan rasanya...

/ masih capek. //

Padahal kamar udah dingin. //

Nah...

/ bisa jadi masalahnya bukan di suhu kamar. //

Tapi di **UDARANYA↘**. //

Banyak orang mengira AC / memasukkan udara segar dari luar. //

Padahal AC split yang umum dipakai di rumah / sebenarnya cuma memutar udara yang sudah ada di dalam kamar. //

Kalau kamar ditutup rapat sepanjang malam...

/ udara segar dari luar jadi sedikit yang masuk. //

Sementara kita terus bernapas. //

Akibatnya...

/ kadar karbon dioksida di kamar bisa naik. //

Dan kamar yang dingin...

/ belum tentu berarti udaranya sehat. //

Makanya...

/ selain mengatur suhu / kita juga perlu memikirkan sirkulasi udara. //

Kalau memungkinkan...

/ beri sedikit ruang untuk udara segar masuk. //

Atau pastikan kamar punya ventilasi yang cukup. //

Karena...

// KAMAR YANG NYAMAN BUKAN CUMA KAMAR YANG DINGIN / TAPI JUGA KAMAR YANG UDARANYA ENAK UNTUK DIHIRUP↘. //

## SHORT 25 — Kenapa Bank Berani Memberi Utang 20 Tahun untuk Sebuah Rumah?

Pernah heran nggak...

/ kalau kita pinjam uang untuk usaha atau beli kendaraan / bank biasanya kasih waktu beberapa tahun saja? //

Tapi kalau buat beli rumah...

/ bank bisa kasih KPR sampai belasan / bahkan puluhan tahun. //

Kenapa bank berani?

Jawabannya...

/ karena rumah punya sesuatu yang sangat penting buat bank. //

**ADA ASETNYA↘.** //

Tanah dan bangunan itu nyata. //

Nggak bisa tiba-tiba dibawa kabur. //

Nggak bisa disembunyikan. //

Dan kepemilikannya juga tercatat secara hukum. //

Jadi buat bank...

/ rumah bisa menjadi jaminan kalau terjadi masalah pembayaran. //

Selain itu...

/ dalam cicilan KPR / kita juga membayar bunga selama bertahun-tahun. //

Artinya...

/ bank mendapatkan pendapatan dari pinjaman tersebut selama periode yang panjang. //

Jadi sebenarnya...

/ ketika bank memberi kita pinjaman selama dua puluh tahun...

/ mereka bukan cuma melihat apakah kita punya pekerjaan atau nggak. //

Mereka juga melihat...

/ **APA YANG MENJADI JAMINANNYA↘.** //

Dan salah satu jaminan terkuat itu...

/ tanah dan bangunan yang kita beli. //

Jadi sebelum tanda tangan KPR...

/ jangan cuma tanya:

“Cicilannya berapa?” //

Tanya juga:

// “SELAMA DUA PULUH TAHUN INI / SEBENARNYA SAYA SEDANG MEMBAYAR APA?”↘ //

## SHORT 26 — Kenapa Membeli Rumah Tidak Selalu Lebih Untung daripada Menyewa?

Dari kecil / kita sering dengar orang bilang:

“Jangan sewa rumah terus. / Mending nyicil. / Nanti rumahnya jadi milik sendiri.” //

Kedengarannya masuk akal. //

Tapi...

/ apakah membeli rumah selalu lebih untung daripada menyewa? //

Belum tentu. //

Karena kalau menghitung biaya rumah...

/ jangan cuma bandingkan uang sewa dengan cicilan KPR. //

Ada bunga bank. /

Ada pajak. /

Ada biaya perbaikan. /

Ada renovasi. /

Ada iuran lingkungan. //

Dan ada satu hal lagi yang sering lupa dihitung. //

**UANG MUKA↘**. //

Misalnya kamu mengeluarkan puluhan atau ratusan juta untuk DP. //

Uang itu...

/ langsung terkunci di rumah. //

Sementara kalau kamu masih muda / masih sering pindah kerja / atau belum tahu mau tinggal di kota mana...

/ menyewa bisa memberi kamu lebih banyak kebebasan. //

Kamu bisa pindah lebih mudah. //

Nggak perlu mikirin cicilan puluhan tahun. //

Bukan berarti beli rumah itu buruk. //

Sama sekali bukan. //

Kalau kamu memang sudah siap menetap...

/ punya penghasilan yang stabil... /

dan rumah itu memang sesuai kebutuhanmu...

/ membeli rumah bisa jadi keputusan yang bagus. //

Tapi jangan beli rumah cuma karena...

/ “kata orang harus punya rumah.” //

Karena...

// RUMAH SEHARUSNYA MEMBANTU HIDUP KITA / BUKAN MALAH MEMBUAT HIDUP KITA TERKUNCI↘. //

## SHORT 27 — Kenapa Banyak Rumah Kosong di Kota Saat Jutaan Orang Butuh Rumah?

Coba bayangkan...

/ di satu sisi / banyak orang masih kesulitan punya rumah. //

Tapi di sisi lain...

/ kita bisa menemukan banyak rumah kosong. //

Apartemen kosong. //

Perumahan baru yang lampunya masih gelap. //

Kok bisa?

/ Bukannya kita kekurangan rumah? //

Nah...

/ ternyata masalahnya nggak sesederhana jumlah rumah. //

Masalahnya adalah...

**RUMAHNYA ADA DI MANA↘.** //

Bayangkan ada rumah yang harganya murah...

/ tapi letaknya jauh banget dari tempat kerja. //

Setiap hari harus naik motor atau kendaraan umum berjam-jam. //

Bensin keluar. /

Ongkos keluar. /

Waktu juga habis. //

Akhirnya...

/ rumahnya memang murah...

/ tapi biaya untuk hidup dari rumah itu malah jadi mahal. //

Sementara rumah yang dekat pusat kota...

/ memang lokasinya enak. //

Tapi harganya bisa terlalu tinggi buat banyak orang. //

Jadi masalah perumahan kita...

/ bukan cuma soal kurang banyak rumah. //

Tapi soal...

/ **RUMAH YANG TERSEDIA BELUM TENTU BERADA DI TEMPAT YANG DIBUTUHKAN ORANG↘.** //

Karena rumah bukan cuma bangunan. //

Rumah harus dekat dengan kehidupan. //

Dekat dengan pekerjaan. //

Dekat dengan transportasi. //

Dan punya akses ke kebutuhan sehari-hari. //

Kalau nggak...

// RUMAHNYA ADA / TAPI KEHIDUPANNYA TERLALU JAUH↘. //

## SHORT 28 — Kenapa Rumah Baru Sekarang Makin Jauh dan Makin Mungil?

Pernah bandingin nggak...

/ rumah orang tua kita dulu / dengan rumah yang banyak dijual sekarang? //

Dulu...

/ halaman bisa luas. //

Ruang rumah juga lebih lega. //

Sekarang...

/ banyak rumah baru ukurannya makin kecil. //

Dan lokasinya juga makin jauh dari pusat kota. //

Kenapa?

/ Salah satu jawabannya sederhana:

**TANAH MAKIN MAHAL↘.** //

Semakin dekat ke pusat kota...

/ harga tanah biasanya makin tinggi. //

Masalahnya...

/ gaji kita nggak selalu naik secepat harga tanah. //

Jadi pengembang punya pilihan. //

Kalau mau harga rumah tetap bisa dijangkau...

/ ukuran rumah dikecilkan. //

Atau...

/ proyeknya dipindah lebih jauh ke pinggir kota. //

Makanya sekarang kita sering melihat rumah yang lebih kecil...

/ tapi perjalanan ke tempat kerja bisa jauh lebih lama. //

Jadi...

/ rumah yang makin mungil dan makin jauh itu / bukan cuma karena tren minimalis. //

Ada tekanan ekonomi di belakangnya. //

Kita sedang berusaha membeli rumah...

/ di tengah harga tanah yang terus naik. //

Dan akhirnya...

// YANG KITA BELI BUKAN CUMA LUAS RUMAH / TAPI JUGA KOMPROMI DENGAN WAKTU PERJALANAN SETIAP HARI↘. //

## SHORT 29 — Kenapa Rumah Tropis Kita Sering Melawan Logika Iklimnya Sendiri?

Coba lihat beberapa rumah baru sekarang. //

Kacanya besar banget. //

Atapnya kotak. //

Warna rumahnya gelap. //

Kalau dilihat di foto...

/ keren banget. //

Tapi coba tinggal di dalamnya / siang-siang. //

Kadang...

/ panasnya bisa bikin kita pengin nyalain AC terus. //

Padahal...

/ kita tinggal di Indonesia. //

Negara tropis. //

Dari dulu / rumah-rumah tradisional di sini sebenarnya sudah punya cara sendiri untuk menghadapi panas dan hujan. //

Atapnya lebar. //

Ada teritisan. //

Banyak bukaan. //

Dan udara bisa mengalir dari satu sisi ke sisi lainnya. //

Tapi sekarang...

/ kita sering mengambil gaya rumah dari tempat lain. //

Masalahnya...

/ desain yang cocok di negara lain / belum tentu cocok di Indonesia. //

Contohnya kaca besar tanpa pelindung. //

Sinar matahari masuk banyak. //

Ruangan jadi panas. //

AC akhirnya bekerja lebih keras. //

Listrik pun ikut naik. //

Jadi rumah yang kelihatan keren di foto...

/ belum tentu nyaman ketika benar-benar ditinggali. //

Sebelum memilih desain rumah...

/ coba jangan cuma tanya:

“Bagus nggak?” //

Tanya juga:

// “COCOK NGGAK / SAMA IKLIM TEMPAT SAYA TINGGAL?”↘ //

Karena rumah yang bagus...

/ bukan cuma yang enak dilihat. //

Tapi yang...

**ENAK DITINGGALI↘.**

## SHORT 30 — Kenapa Lebar Jalan Depan Rumah Menentukan Harga Tanah?

Pernah perhatiin nggak...

/ dua tanah di daerah yang sama / luasnya sama persis...

/ tapi harganya bisa beda jauh? //

Kadang bedanya...

/ cuma karena jalan di depannya. //

Satu tanah ada di gang sempit. //

Motor masih bisa masuk...

/ tapi mobil susah. //

Sementara yang satu lagi / ada di jalan yang lebih lebar. //

Dua mobil bisa papasan. //

Nah...

/ kenapa jalan bisa bikin harga tanah beda? //

Karena saat membeli rumah atau tanah...

/ kita sebenarnya nggak cuma membeli tanahnya. //

Kita juga membeli **AKSES↘**. //

Jalan yang lebih lebar / bikin rumah lebih gampang dicapai. //

Mobil bisa masuk. //

Barang bisa diantar. //

Renovasi juga lebih gampang. //

Dan kalau suatu hari rumah itu mau dijual lagi...

/ calon pembelinya juga lebih banyak. //

Sebaliknya...

/ kalau jalannya terlalu sempit...

/ nggak semua orang mau tinggal di sana. //

Mobil susah masuk. //

Parkir susah. //

Akses darurat juga bisa jadi masalah. //

Jadi...

/ jangan cuma lihat luas tanah ketika mau membeli rumah. //

Coba berdiri di depan rumahnya. //

Lihat jalannya. //

Lihat seberapa mudah kamu keluar masuk setiap hari. //

Karena pada akhirnya...

// KITA BUKAN CUMA MEMBELI RUANG DI DALAM PAGAR / TAPI JUGA MEMBELI KEMUDAHAN UNTUK TERHUBUNG DENGAN DUNIA DI LUAR PAGAR↘. //
