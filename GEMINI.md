# Nugi Content Creator — Working Instructions

For YouTube topic discovery, research, and story planning, follow [Creator-Led Research Workflow](docs/CREATOR_LED_RESEARCH_WORKFLOW.md).

## Default creator workflow

- Prepare research, source links, fact-check notes, chronology, causal explanations, and a structured story outline.
- **Do not write the full teleprompter script by default.** Nugi writes the script personally.
- Do not turn an outline into read-aloud narration, even if that seems like the natural next production step.
- Keep source links visible and distinguish verified facts from leads, interpretations, and uncertain claims.
- Do not invent facts or force a dramatic story unsupported by evidence.
- Do not modify code, add dependencies, create agents/services, or refactor architecture to implement this editorial preference.
- For research-and-outline-only requests, do not invoke an end-to-end production entry point if it will generate a script. Use the documented research capabilities and return the research brief plus outline.
- Only generate or modify a script when Nugi explicitly asks for that specific help.

These are operating instructions for AI assistants working in this repository. They do not change the behavior of the existing production pipeline or MCP tools by themselves.
