## Sumber Kebenaran Aktif (Active Source of Truth)

Repositori `nugi-konten-kreator` berdiri sendiri sebagai **NUGI HUMAN–PLACE CONTENT INTELLIGENCE ENGINE** dengan identitas editorial:

$$\text{HUMAN} \times \text{PLACE} \times \text{CHANGE} \times \text{WHY}$$

Seluruh arsitektur aktif, riset, penalaran kausal, dan pembuatan narasi dibatasi secara ketat pada folder aktif berikut:
- `core/` — Nilai brand, positioning, Content DNA, kebijakan editorial.
- `research/` — Metodologi riset, mode riset, evaluasi sumber, dan verifikasi fakta.
- `thinking/` — Mesin sudut pandang, penalaran kausal, dekonstruksi WHY, dan jembatan Human–Place.
- `skills/` — Kontrak kerja agentik untuk discovery pertanyaan, riset, dan penulisan skrip.
- `knowledge/` — Basis pengetahuan psikologi manusia, pengaruh, daya ingat, dan narasi.
- `engine/` — Pipeline Python mandiri (question mining, intent classification, story type, revelation, retrieval, video/visual specs).
- `evaluation/` — Evaluasi kualitas konten, gerbang editorial, dan loop pembelajaran.
- `docs/` — Dokumentasi sistem dan arsitektur aktif.
- `tests/` — Pengujian unit dan integrasi otomatis.
- `output/` — Hasil riset, skrip, dan aset visual narasi Nugi.
