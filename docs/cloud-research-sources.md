# Cloud Research Sources

The manual **research** operation combines independent discovery providers and then attempts bounded extraction from the resulting URLs. It does not publish content or treat search snippets as verified facts.

## Enabled by default (no API key)

- Google News RSS search (Indonesia / Indonesian language by default)
- GDELT DOC API
- OpenAlex works API
- Crossref works API
- Europe PMC search API
- The repository's existing editorial discovery operation (saved separately under `idea-discovery/`)

A provider error is recorded in the discovery JSON/Markdown and does not stop other providers. Search result counts vary by provider and query.

## Optional providers

Configure these in **GitHub repository Settings → Secrets and variables → Actions**:

| Name | Type | Purpose |
| --- | --- | --- |
| `SEARXNG_BASE_URL` | Variable | Base URL of a reachable SearXNG instance that has JSON output enabled. A self-hosted instance must be publicly reachable by GitHub Actions, or available through a secure tunnel. |
| `BRAVE_SEARCH_API_KEY` | Secret | Enables Brave News Search API |
| `TAVILY_API_KEY` | Secret | Enables Tavily news-focused web search |
| `EXA_API_KEY` | Secret | Enables Exa web search |
| `MEDIACLOUD_API_TOKEN` | Secret | Enables Media Cloud provider when the token has API access |
| `EXTRA_RSS_FEEDS` | Variable | Semicolon-separated RSS/Atom feed URLs, including feeds generated by RSSHub or exposed by a FreshRSS instance |

Optional APIs are skipped if their key/URL is absent. API access, quotas, authentication, and pricing are controlled by each provider. Do not commit keys to the repository.

## FreshRSS and RSSHub

FreshRSS is a feed reader, not a search API. RSSHub generates feed URLs. To ingest feeds from either service, add the resulting RSS/Atom URLs to `EXTRA_RSS_FEEDS`, separated by semicolons. The URLs must be reachable from GitHub-hosted runners. Do not expose an authenticated/private feed URL publicly.

## Article extraction and evidence

- Search titles, snippets, RSS descriptions, and scholarly metadata are discovery leads, not fact verification.
- The extraction step tries to resolve Google News wrapper URLs to publisher URLs. It extracts accessible HTML only; it does not bypass paywalls, logins, or access controls.
- PDFs and non-HTML pages may be listed as unsupported. OpenAlex, Crossref, and Europe PMC results can be metadata/abstract pages rather than full-text articles.
- Each source record should preserve the discovery URL, resolved URL when available, provider, publication metadata, extraction status, and error details.
- Common Crawl is an archive/corpus rather than a real-time search provider; it is not queried by this workflow.

## Run

Open **Actions → Nugi Cloud Workbench → Run workflow**, choose `research`, set count (1–20), and optionally provide semicolon-separated queries. The artifact is retained for 30 days. Results are downloaded from the completed workflow's Artifacts section.
